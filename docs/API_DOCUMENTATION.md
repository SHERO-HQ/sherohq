# SheroTech — API Reference & Integration Guide

> **Purpose**: Complete reference for all REST API endpoints provided by the SheroTech native backend. Includes authentication requirements, request/response shapes, validation rules, and error handling standards.

---

## 1. Core API Conventions

### Base URL
All API routes are served under `/api` relative to the application origin.

### Response Standard (`src/lib/api-utils.ts`)
All endpoints return consistent JSON response envelopes generated by `apiResponse` helper methods.

#### Success Response (HTTP 200/201)
```json
{
  "success": true,
  "data": { ... },
  "message": "Optional descriptive success message"
}
```

#### Error Response (HTTP 400/401/403/404/429/500)
```json
{
  "success": false,
  "error": "Human-readable error explanation",
  "details": null
}
```

### Security & Headers
State-changing API methods (`POST`, `PUT`, `DELETE`, `PATCH`) enforce security middleware:
* **CSRF Token Header**: `x-csrf-token: <token>` (must match the `shero_csrf` cookie token).
* **Content Type**: `application/json`.
* **Rate Limits**: Headers returned on rate-limited endpoints (`X-RateLimit-Limit`, `X-RateLimit-Remaining`).

## 2. Authentication Endpoints

### User Authentication (`/api/auth`)

#### `POST /api/auth/login`
Authenticates a public client user. Implements session rotation and account lockout checks.
* **Headers**: `x-csrf-token`
* **Request Body**:
  ```json
  {
    "email": "client@example.com",
    "password": "Password123"
  }
  ```
* **Response (200 OK)**:
  ```json
  {
    "success": true,
    "data": {
      "user": {
        "id": "usr_123",
        "email": "client@example.com",
        "fullName": "Jane Doe"
      }
    }
  }
  ```
* **Status Codes**: `200` (Success), `400` (Validation Error), `401` (Invalid Credentials), `429` (Account Locked / IP Rate Limited).

#### `POST /api/auth/register`
Registers a new user account with strict password validation rules.
* **Request Body**:
  ```json
  {
    "fullName": "Jane Doe",
    "email": "client@example.com",
    "password": "Password123",
    "phone": "+233200000000"
  }
  ```
* **Response (201 Created)**: `201` with created user payload.

#### `GET /api/auth/me`
Retrieves the currently authenticated user's session profile.
* **Response (200 OK)**: User profile object or `401 Unauthorized`.

#### `POST /api/auth/logout`
Terminates the active user session and clears session cookies.

---

### Admin Authentication (`/api/admin-auth`)

#### `POST /api/admin-auth/login`
Authenticates administrative users with optional Multi-Factor Authentication (MFA/TOTP).
* **Request Body**:
  ```json
  {
    "username": "admin_user",
    "password": "AdminPassword123",
    "code": "123456" // Required if MFA is enabled
  }
  ```
* **Response (200 OK)**: Session details + MFA status.

#### `POST /api/admin-auth/mfa`
Enables, verifies, or disables TOTP MFA for administrative accounts.
* **Actions Supported**: `setup`, `verify`, `disable`.

## 3. Products & Catalog Endpoints

#### `GET /api/products`
Retrieves product items from the catalog with support for category filters, search terms, and stock filters.
* **Query Parameters**:
  * `category` (string, optional)
  * `search` (string, optional)
  * `inStock` (boolean, optional)
  * `limit` (integer, default: 20)
* **Response (200 OK)**:
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "prod_01",
        "title": "Enterprise Server Node",
        "slug": "enterprise-server-node",
        "price": 12500.00,
        "currency": "GHS",
        "category": "servers",
        "inStock": true
      }
    ]
  }
  ```

#### `GET /api/products/[slug]`
Fetch detailed product information by its unique URL slug.

## 4. Orders & Payment Endpoints

#### `POST /api/orders`
Submits a new customer checkout order.
* **Headers**: `x-csrf-token`
* **Request Body**:
  ```json
  {
    "customerInfo": {
      "fullName": "Jane Doe",
      "email": "jane@example.com",
      "phone": "+233240000000"
    },
    "items": [
      { "productId": "prod_01", "quantity": 1, "price": 12500.00 }
    ],
    "paymentMethod": "momo",
    "deliveryAddress": "12 Accra Road, East Legon"
  }
  ```
* **Response (201 Created)**:
  ```json
  {
    "success": true,
    "data": {
      "orderId": "ORD-2026-8812",
      "totalAmount": 12500.00,
      "accessToken": "tok_sec_991823"
    }
  }
  ```

#### `POST /api/payments/initialize`
Initializes a payment request via the Hubtel Payment Gateway.
* **Request Body**:
  ```json
  {
    "orderId": "ORD-2026-8812",
    "paymentMethod": "momo",
    "phoneNumber": "0240000000",
    "network": "MTN"
  }
  ```
* **Response (200 OK)**: Contains Hubtel payment checkout URL and reference ID.

#### `POST /api/payments/webhook`
Callback handler for async transaction status updates from Hubtel. Validated with signature hash.

#### `GET /api/orders/track`
Public endpoint allowing customers to track order status using `orderId` and `accessToken`.

## 5. Inquiries, Consultations & Support

#### `POST /api/consultations`
Schedules a technical discovery session or software engineering consultation.
* **Request Body**:
  ```json
  {
    "name": "Alex Mensah",
    "email": "alex@enterprise.com",
    "phone": "+233201112222",
    "company": "Enterprise West Africa",
    "serviceInterest": "Managed IT Infrastructure",
    "preferredDate": "2026-08-20T10:00:00Z",
    "message": "Looking to upgrade on-premise server architecture."
  }
  ```

#### `POST /api/feedback` / `POST /api/inquiries`
Public submission forms for general inquiries, partner leads, and feedback.

#### `GET /api/tickets` / `POST /api/tickets`
Client support ticket submission and tracking thread APIs.

---

## 6. Admin Command Center Endpoints

> **Authorization**: All `/api/admin/*`, `/api/reports`, and `/api/analytics` endpoints require an active, valid admin session token.

* `GET /api/admin`: General system configuration and stats overview.
* `GET /api/analytics`: Sales metrics, conversion rates, and revenue breakdown.
* `GET /api/reports`: Generates downloadable summary reports (supports `format=csv`, `format=excel`, `format=pdf`).
* `GET /api/carts`: Lists active guest carts and abandoned cart recovery statuses.

---

## 7. Webhooks & Background Operations

* `POST /api/webhooks/whatsapp`: Inbound webhook listener for official WhatsApp Business integration.
* `GET /api/cron`: Scheduled execution route (secured via `CRON_SECRET` header) triggering abandoned cart reminders and retry queues.
