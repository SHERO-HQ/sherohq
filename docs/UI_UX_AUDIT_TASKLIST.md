# SheroTech UI/UX Task List

Based on the current site audit and the UI UX Pro Max direction, this task list is ordered by impact on clarity, trust, conversion, and premium feel.

## Goal

Make the site feel more premium, clearer, and more conversion-oriented without adding visual noise or unnecessary motion.

## Priority 1: Positioning and Proof

- [ ] Rewrite the home hero so the first screen clearly says SheroTech sells business-grade hardware and managed IT/services.
- [ ] Replace abstract hero language like "Redefine Possible" with a concrete value proposition and outcome.
- [ ] Add visible trust/proof blocks across the site, such as reviews, delivery count, warranty, returns, or customer logos.
- [ ] Standardize the support response promise so the site uses one consistent SLA everywhere.
- [ ] Add proof-oriented content near the primary CTA on the home and contact pages.

## Priority 2: Visual Restraint

- [ ] Reduce layered background effects on the contact page to one subtle decorative treatment per section.
- [ ] Remove or simplify the pulsing orb on the support page.
- [ ] Tone down pattern overlays and particle effects on the hero so the page feels calmer and more premium.
- [ ] Keep motion purposeful and sparse, not decorative by default.

## Priority 3: Readability and Hierarchy

- [ ] Audit all micro text on product cards, support chips, and contact badges.
- [ ] Raise the smallest labels from 8px to at least 12px where possible.
- [ ] Ensure badge and label contrast meets accessibility expectations on both light and dark surfaces.
- [ ] Reduce reliance on mono uppercase micro-labels where they do not add real utility.

## Priority 4: Storefront Conversion

- [ ] Make the product card primary CTA more obvious on mobile and desktop.
- [ ] Reduce the visual weight of secondary metadata on product cards.
- [ ] Add clear warranty or return context to product listing or product detail surfaces.
- [ ] Show aggregate store proof, not just per-item ratings.
- [ ] Keep the cart and buy actions visibly distinct and easy to hit on small screens.

## Priority 5: Checkout Clarity

- [ ] Rename step 2 from "Shipping" to "Shipping Details" or "Delivery Address."
- [ ] Surface payment/security cues earlier in the flow.
- [ ] Review the 45-second AI help trigger and remove, delay, or make it user-initiated.
- [ ] Make the checkout flow feel supportive rather than interruptive.

## Priority 6: Contact and Support UX

- [ ] Change vague primary CTA wording like "Start Conversation" to a clearer outcome-driven message.
- [ ] Promote the response-time promise visually near the contact form title or CTA.
- [ ] Tighten the FAQ/support card hierarchy so the page reads top-to-bottom without competing emphasis.
- [ ] Keep support resources easy to scan, with a stronger visual distinction between guide links and social links.

## Priority 7: Admin Content Quality

- [ ] Mark required and optional fields clearly in the product form.
- [ ] Add inline help text for specification rows and other structured fields.
- [ ] Add a preview mode so admins can check storefront appearance before saving.
- [ ] Make draft recovery and form saving behavior obvious to the user.

## Priority 8: Brand Cleanup

- [ ] Replace generic launch/space imagery in the final CTA if it does not match the brand.
- [ ] Rework end-of-page CTA copy to sound more specific to SheroTech.
- [ ] Align all CTA language with the same brand tone and promise.

## Suggested Execution Order

1. Hero positioning and proof.
2. Visual simplification on Contact and Support.
3. Typography and micro-text cleanup.
4. Storefront card and CTA hierarchy.
5. Checkout wording and help behavior.
6. Admin form guidance.

## Definition of Done

- The home page immediately explains what SheroTech offers.
- The site uses one consistent trust and response-time message.
- Micro text is readable and deliberate.
- Decorative motion is minimal and intentional.
- Checkout, contact, and product flows feel easier to trust and complete.
