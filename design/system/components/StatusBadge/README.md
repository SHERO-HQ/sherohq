# StatusBadge

Honest status label for products and projects: Live, In development, In validation.

- Every product and project card carries one. This is the honesty rule made visible: nothing unreleased looks released.
- `live` → `accent` on `accent-subtle`; `dev` → `warning` on `warning-subtle`; `validation` → `primary` on `info-subtle`.
- The dot plus the words carry the meaning; colour is never the only signal.
- Consumer provides: the status. Labels are fixed: "Live", "In development", "In validation".
