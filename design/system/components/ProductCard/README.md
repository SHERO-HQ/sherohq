# ProductCard

One of SHERO's own products with its status and a waitlist action.

- On SHERO pages the card stays in SHERO tokens; the product's own colours appear only on its product page.
- Product name in `meta` style (not the product logo) so the grid reads as one family.
- A `StatusBadge` is required. Never a screenshot of an unreleased product presented as live.
- Action: "Join the waitlist" for unreleased products; "Visit" once live.
