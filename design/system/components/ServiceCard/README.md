# ServiceCard

One service with its promise and what it covers; used in a grid of four.

- `surface-raised`, 1px `border`, `radius-md`, padding `space-5`. No shadow, no coloured left border.
- A two-digit index in `meta` style replaces icons: engineered, and it avoids generic icon sets.
- Title `h3` in `heading`; one sentence in `body-sm` `ink-secondary`.
- The whole card may link to the service; if so, hover changes the border to `primary`.
