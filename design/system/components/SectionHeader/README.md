# SectionHeader

Opens every homepage and page section: mono eyebrow, heading, one-paragraph intro.

- Eyebrow: `eyebrow` style in `accent`, lowercase, prefixed `// `. One per section, two to four words.
- Heading: `h2` in `heading`. A plain statement, not a slogan.
- Intro: `body-lg` in `ink-secondary`, max width `measure`. Optional.
- Space: `space-8` below the header before section content on desktop, `space-6` on mobile.
