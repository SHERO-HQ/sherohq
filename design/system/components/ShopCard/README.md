# ShopCard

A refurbished device listing: image, name, specs, grade and price.

- Photo on `surface`, `radius-lg`, 4:3. Real photos of the actual device, never brand stock images.
- Condition first ("UK-used · Grade A++"), then the name in `h3` at 18px, specs in `meta`.
- Price in `price` style (Red Hat Mono), always "GHS" plus a thousands separator.
- No brand logos on cards. Example values here are placeholders.
