# Button

Primary for the one main action on a view, secondary for everything else; nearly square, never pill-shaped.

- Variants: `sh-btn--primary` (fill `primary`, text `on-primary`), `sh-btn--secondary` (outline `border-strong`, text `primary`), and the text link `sh-link`.
- One primary per view. Hero pairs primary + secondary.
- Height 44px (36px with `sh-btn--sm`), `radius-sm`, `label` type. Focus: 2px `focus` ring, 2px offset.
- Labels are verbs naming the result: "Book a free consultation", "Join the waitlist". Never "Learn more" alone or "Click here".
- Consumer provides: the label and the destination.
